# npx dice — 仕様書

[English](README.md)

## 概要

コマンドラインでサイコロ（1〜6）をN個振るCLIツール。

```bash
npx dice <number> [options]
```

---

## コマンド仕様

| コマンド | 動作 |
|---|---|
| `npx dice` | ヘルプ表示（英語） |
| `npx dice help` | ヘルプ表示（英語） |
| `npx dice help --ja` | ヘルプ表示（日本語） |
| `npx dice <1〜9>` | ダイスをN個表示 |
| `npx dice <0以下・10以上・文字列>` | エラーアラート表示 |

---

## オプション仕様

| オプション | 内容 |
|---|---|
| `--label` | ダイスの下にラベル表示 |
| `--art` | 絵文字ダイス表示（⚀〜⚅） |
| `--art-box` | テキスト枠ダイス表示 |
| `--art --label` | 絵文字ダイス＋下にラベル |
| `--art-box --label` | テキスト枠ダイス＋下にラベル |
| `--art --art-box` | ❌ エラー（競合） |
| `--ja` | ヘルプ表示時のみ有効（日本語化）。ダイス実行時は無視 |

---

## 出力イメージ

### デフォルト

```
3 1 5
```

### `--label`

```
3       1       5
Dice 1  Dice 2  Dice 3
```

### `--art`

```
⚂ ⚀ ⚄
```

### `--art --label`

```
⚂      ⚀      ⚄
Dice 1  Dice 2  Dice 3
```

### `--art-box --label`

```
┌─────┐  ┌─────┐  ┌─────┐
│ ●   │  │  ●  │  │ ● ● │
│  ●  │  │     │  │     │
│   ● │  │  ●  │  │ ● ● │
└─────┘  └─────┘  └─────┘
Dice 1   Dice 2   Dice 3
```

---

## エラーメッセージ仕様

| ケース | メッセージ |
|---|---|
| 0以下・10以上・文字列 | `Error: Please specify a number between 1 and 9` |
| `--art --art-box` 同時指定 | `Error: --art and --art-box cannot be used together` |

- エラーメッセージは常に英語
- `--ja` はエラーメッセージには影響しない

---

## 言語対応

| 言語 | オプション | ステータス |
|---|---|---|
| 英語 | デフォルト | ✅ 対応 |
| 日本語 | `--ja` | ✅ 対応（ヘルプのみ） |
| その他 | 未定 | 要望があれば追加（拡張可能な構造で実装） |

---

## 制約まとめ

- ダイスの個数は **1〜9** のみ有効
- `--art` と `--art-box` は同時使用不可
- `--ja` はヘルプ表示時のみ有効。それ以外のコマンドでは無視する
